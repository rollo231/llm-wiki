# LLM 위키

[카파시의 gist](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)가 제안한 LLM 위키 패턴을 바탕으로 만드는 개인 지식 베이스입니다. [Obsidian](https://obsidian.md)으로 읽고, LLM 에이전트가 쓰고 관리합니다.

Obsidian은 IDE, LLM은 프로그래머, 위키는 코드베이스.

특정 강의나 주제에 한정하지 않고, 공부하거나 조사하면서 접하는 강의, 문서, 책, 논문, 기술 자료 등을 하나의 지식 베이스로 축적하는 것을 목표로 합니다.

질문할 때마다 원본 자료에서 답을 다시 찾아내는 대신, 에이전트가 자료를 읽을 때마다 핵심 내용을 위키에 통합합니다. 새로운 자료는 기존 지식과 연결되고, 관련 개념과 도구가 갱신되며, 필요한 경우 서로 다른 자료의 주장이나 관점을 비교합니다.

이렇게 만들어진 위키는 자료와 질문이 쌓일수록 함께 성장합니다.

사람은 무엇을 읽고 무엇을 질문할지 결정하고, 에이전트는 요약·교차참조·정리·기록을 담당합니다.

## 구조

```text
llm-wiki/
├─ CLAUDE.md     # 에이전트가 따르는 스키마
├─ README.md     # 이 소개 문서
├─ index.md      # 모든 페이지 목록
├─ log.md        # 활동 기록 (시간순, 추가만)
├─ raw/          # 원본 자료 — gitignore, 불변
└─ wiki/
   ├─ sources/   # 자료별 요약
   ├─ entities/  # 도구·제품·조직·사람·강의 등
   ├─ concepts/  # 개념·방법·주제
   └─ notes/     # 비교·분석·종합
```

`raw/`는 원본 자료를 보관하는 로컬 디렉터리이며 Git에는 포함하지 않습니다. 공개 저장소에는 원본 대신 각 source 페이지에 출처와 인용을 기록합니다.

전체 작성 및 관리 규칙은 [`CLAUDE.md`](CLAUDE.md)를 참고하세요.

## 작업

- 인제스트: 사람이 `raw/`에 자료를 넣고 요청하면 에이전트가 읽고, 핵심 내용을 사람과 논의한 뒤 정리합니다. source 페이지를 만들고 관련 entity·concept 페이지를 갱신한 뒤 `index.md`와 `log.md`를 업데이트합니다.
- 질의: 에이전트는 `index.md`에서 시작해 관련 페이지와 출처를 따라가며 인용과 함께 답합니다. 다시 활용할 가치가 있는 분석이나 결론은 note 페이지로 남겨 질문을 통해 얻은 지식도 축적합니다.
- 린트: 위키에 쌓인 모순, 오래된 주장, 고아 페이지, 빠진 교차참조, 근거가 부족한 내용과 자료 공백을 점검합니다.

## 시작하기

1. 저장소를 clone합니다.
2. 이 폴더를 [Obsidian](https://obsidian.md) 볼트로 엽니다.
3. `raw/`에 학습하거나 분석할 자료를 넣습니다.
4. 에이전트에게 인제스트를 요청합니다. 에이전트가 핵심을 논의한 뒤 페이지를 쓰고, `main`에 커밋하고 push합니다.
5. 생성되거나 수정된 위키 페이지와 커밋을 검토합니다.

이 저장소는 완성된 지식 모음이라기보다, 사람과 LLM이 함께 지식을 쌓고 관리하는 방법을 실험하는 지식 베이스입니다.
