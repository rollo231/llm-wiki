# AI 데이터 엔지니어링

데이터 엔지니어링의 소비자가 사람(경영진·분석가)에서 모델(학습·추론)로 바뀔 때의 데이터 엔지니어링. [[AI 데이터 엔지니어링 강의]]가 이 대비를 강의 전체의 틀로 쓴다.

## 기존 DE와의 차이

| | 기존 DE | AI DE |
|---|---|---|
| 소비자 | 경영진·분석가 | 모델(학습·추론) |
| 데이터 | 정형 테이블 | 비정형(이미지·오디오·텍스트)까지 |
| 흐름 | 수집 → 정제 → DW → BI | 학습 데이터 준비 · 서빙 · 비정형 처리 |
| 실패의 모습 | 틀린 대시보드 | 에러 없이 틀린 예측 |

AI DE의 역할은 세 갈래다([[AI DE 강의 1-01 기존 DE와 AI DE]]):

- 학습: 고품질 데이터 준비와 버전 관리, 학습 파이프라인 자동화, GPU 스케줄링.
- 추론: 서빙 환경, 응답 속도 최적화, 비용 효율적 인프라.
- 비정형 데이터: 포맷 처리, 텐서·벡터 변환, 대용량 저장·검색.

## 두 마인드셋

- Latency: 추론 쪽의 요구다([[지연 시간과 처리량]]).
- Versioning: 학습 쪽의 요구(재현성)다([[데이터와 모델 버전 관리]]).

## 역할의 확장

Part 1 후반은 DE의 책임을 파이프라인 구축 너머로 넓힌다.

- "배관공"에서 데이터 품질·거버넌스 지휘자로. 신선도 SLO, 데이터 계약, 재학습 오케스트레이션을 맡는다([[AI DE 강의 1-13 Skew와 Drift]]).
- 데이터를 내부 고객(데이터 사이언티스트·모델)이 쓰는 제품처럼 관리한다(Data as a Product).
- 최종 목표는 데이터 민주화다. 마케터·기획자도 스스로 안전하게 데이터를 찾아 쓰는 상태를 말한다([[AI DE 강의 1-15 데이터 거버넌스와 카탈로그]]).

Part 2는 같은 확장을 인프라와 운영 쪽에서 다시 그린다.

- 온프레미스의 서버 관리자에서 클라우드 시대의 데이터 아키텍트로, 그리고 계산이 발생하는 흐름(GPU를 언제·어디서·왜 쓰나)까지 설계하는 사람으로([[AI DE 강의 2-01 데이터 파이프라인의 진화와 데이터 엔지니어]]).
- MLOps에서는 데이터 파이프라인·피처 스토어·학습/추론 데이터 일관성·자동 재학습을([[AI DE 강의 2-02 MLOps와 ML 생애주기]]), LLMOps에서는 지식 파이프라인과 운영 가능한 컨텍스트를 책임진다([[AI DE 강의 2-03 LLMOps]]).

## 관찰

- [[AI DE 강의 1-03 기술 스택과 툴 생태계]]가 제시하는 스택은 기존 DE 스택에 PyTorch를 더한 모습이다. Part 1에서 AI 쪽 고유의 부품은 피처 스토어와 벡터 DB 정도이고, 나머지는 기존 DE 기술을 "소비자가 모델일 때" 다시 읽는 방식이다. Part 1까지 읽은 시점에 위키가 한 관찰이다.
- Part 2에서 AI 쪽 고유의 부품은 서빙 계층(모델 서버, 동적 배칭, GPU, 양자화)으로 옮겨 간다. Part 2가 보여 주는 채용 공고의 선호 요건 첫 줄도 Spring Boot·Kotlin/Java 백엔드 경험이다. 이 코스가 그리는 AI DE는 데이터 엔지니어와 백엔드·플랫폼 엔지니어의 경계에 있다. Part 2까지 읽은 시점에 위키가 한 관찰이다.
- Part 3에서 AI 쪽 고유의 부품은 모델 앞단의 컨텍스트 계층(시맨틱 계층, 지식 그래프, GraphRAG)이다. 저장 기술(RDB·NoSQL·그래프 DB)은 수단으로 다루고, 강의의 무게는 "의미를 기계가 읽을 수 있게 만드는 일"에 있다. Part 2가 그린 LLMOps의 "지식 파이프라인"([[LLMOps]])을 구체화한 것으로 읽힌다. Part 3까지 읽은 시점에 위키가 한 관찰이다.
- Part 4에서 AI 쪽 고유의 부품은 GPU다(아키텍처, MIG·MPS 분할, RAPIDS, GPU 스케줄링). 나머지 절반(CAP·복제·합의, 캐싱, 브로커, 워터마크)은 AI와 무관한 분산 시스템의 기본기이고, 강의도 AI 사례는 예시로만 붙인다. 운영 덱(Ch5)은 온라인 추론·배치 추론·학습·모니터링 네 경로를 나눠 각각 SLO를 거는 방식으로 두 절반을 잇는다. Part 4까지 읽은 시점에 위키가 한 관찰이다.
