# 온톨로지

한 도메인의 개념(클래스), 개체(인스턴스), 속성, 관계, 제약을 기계가 읽을 수 있게 정의한 명세다. [[AI DE 강의 3-08 온톨로지와 RDFS·OWL]]은 "공유된 개념과 관계의 공식 명세"라고 부른다. 스키마가 저장 구조(컬럼·타입·제약)를 보장한다면 온톨로지는 "이 데이터가 현실에서 무엇을 뜻하는가"와 "다른 시스템의 어떤 개념과 같은가"를 적는다. 온톨로지가 정의한 틀에 실제 개체와 사실을 채운 것이 [[지식 그래프]]다.

## 구성 요소

| 요소 | 뜻 | 예 (이커머스 / 데이터 플랫폼) |
|---|---|---|
| 클래스 | 개념의 유형. "~의 한 종류인가"로 판단 | `Customer`, `PremiumCustomer` / `Dataset`, `FactTable` |
| 인스턴스 | 실제 개별 대상. 운영 식별자와 함께 관리됨 | `customer_1001` / `dataset_sales_daily` |
| 속성 | 설명 값(Data Property) 또는 다른 대상(Object Property) | `hasEmail` / `usesDataset` |
| 관계 | 두 개체를 잇는 의미 있는 연결. 방향과 업무 의미가 이름에 드러나야 함 | `placesOrder` / `produces` |
| 제약 | 모델이 따라야 하는 규칙 | 모든 주문은 한 명의 구매자와 연결 |

모델링의 판단 기준(질의에서 출발, 관계에 정보가 많이 붙으면 개체로 승격, 테이블 = 클래스로 옮기지 않기)은 [[AI DE 강의 3-09 온톨로지 모델링 원칙]]에 있다.

## 표현 표준: RDF, RDFS, OWL

| 층 | 하는 일 | 대표 어휘 |
|---|---|---|
| RDF | 모든 사실을 주어-술어-목적어 트리플로 적는 데이터 모델 | `rdf:type`, `rdf:Property` |
| RDFS | 클래스 계층과 속성의 domain·range 같은 가벼운 스키마 어휘 | `rdfs:Class`, `rdfs:subClassOf`, `rdfs:domain`, `rdfs:range` |
| OWL | 동치·배타·역관계·대칭·추이·기수 같은 논리 규칙 | `owl:equivalentClass`, `owl:disjointWith`, `owl:TransitiveProperty` |

RDF 자체와 Property Graph의 비교는 [[그래프 데이터 모델]]에 있다. RDF Schema 1.1은 2014-02-25 W3C Recommendation이고, OWL 2는 2009-10-27에 Recommendation이 되었고 현행 문서는 2012-12-11 Second Edition이다(https://www.w3.org/TR/rdf-schema/ · https://www.w3.org/TR/owl2-overview/ , 2026-09-28 확인). RDF 1.2는 2026-09 현재 Candidate Recommendation, RDF 1.2 Schema는 Working Draft 단계다(검증 subagent 보고).

### domain과 range는 추론 규칙이다

강의(3-08 p9, 3-09 p27)는 domain·range를 "이 속성의 목적어는 어떤 클래스여야 한다"는 제약처럼 설명한다. 명세의 정의는 다르다.

> rdfs:range is an instance of rdf:Property that is used to state that the values of a property are instances of one or more classes. The triple P rdfs:range C states that ... the resources denoted by the objects of triples whose predicate is P are instances of the class C.

> rdfs:domain ... is used to state that any resource that has a given property is an instance of one or more classes.

즉 `worksAt rdfs:range Organization`이 있을 때 `Jeff worksAt 서울`을 적으면, RDFS 추론기는 오류를 내지 않고 "서울은 Organization이다"를 새 사실로 끌어낸다. 명세는 이 정보를 어떻게 쓸지 응용에 맡긴다: "RDF Schema provides a mechanism for describing this information, but does not say whether or how an application should use it. ... data checking tools might use this to help discover errors in some data set, an interactive editor might suggest appropriate values, and a reasoning application might use it to infer additional information from instance data." [https://www.w3.org/TR/rdf-schema/ §4, 2026-09-28 확인]

그래서 "이어야 한다"를 강제하려면 검증 언어가 따로 필요하고, 그 자리가 [[SHACL]]이다. 이 구분이 강의에서 가장 크게 흐려진 곳이다. 하나 더: `rdf:Property`는 `rdf:` 네임스페이스 어휘이고 RDFS 문서가 설명할 뿐인데, 3-08 p9는 RDFS가 정의하는 목록에 넣는다.

### OWL은 언제 필요한가

강의는 OWL이 필요한 경우를 규칙 기반 의미 추론이 실제 가치가 있을 때로 좁힌다(동일 개체 판별, 상속·배타 규칙을 품질 검증에 쓸 때, 정책·권한 규칙의 논리 검증, GraphRAG의 타입·관계 추론). 단순 메타데이터 수집, 계보 시각화, 태그 검색이면 과설계라고 한다. [[AI DE 강의 3-10 지식 그래프 파이프라인]] 8단계의 "A가 B의 upstream이고 B가 C의 upstream이면 간접 영향"은 `upstreamOf`를 `owl:TransitiveProperty`로 선언하면 얻는 추론인데, 강의는 수단을 밝히지 않는다. 위키의 보충이다.

## 관계형 데이터에서 온톨로지로

원천 테이블을 온톨로지 어휘의 트리플로 바꾸는 매핑 표준이 두 가지 있다([[AI DE 강의 3-10 지식 그래프 파이프라인]] 6단계).

- Direct Mapping: 테이블·컬럼 구조를 거의 그대로 RDF로 옮긴다. 빨리 시작할 수 있지만 목표 어휘를 고를 수 없다.
- R2RML: 원하는 온톨로지 어휘로 커스텀 매핑한다. 관계형 DB 전용이다.

둘 다 2012-09-27 W3C Recommendation이다(https://www.w3.org/TR/r2rml/ · https://www.w3.org/TR/rdb-direct-mapping/ , 2026-09-28 확인). 강의는 R2RML을 "실무에서 많이 사용"이라고 하지만, CSV·JSON·XML까지 다루는 RML도 흔하다. RML-Core 명세는 스스로를 "a superset of the W3C-standardized mapping language R2RML"이라 하고, W3C 표준이 아니라 KG-Construct Community Group의 초안이다(https://kg-construct.github.io/rml-core/spec/docs/ , 2026-09-28 확인). 가상 지식 그래프(Virtual Knowledge Graph) 방식도 있다. Ontop은 데이터를 원천 DB에 둔 채 SPARQL 질의를 SQL로 바꿔 실행하고, 매핑에 R2RML을 쓴다(https://ontop-vkg.org/guide/ , 2026-09-28 확인). 강의가 말하는 "매핑 명세를 코드와 분리해 관리하라"는 조언은 어느 도구에나 맞는다.

## 온톨로지가 있다고 말할 수 있는가

3-08의 판단 질문은 세 개다. 개념 정의서가 있는가, 관계가 컬럼 연결이 아니라 의미로 정의되어 있는가, 기계가 그 정의를 읽고 검증·매핑·추론·검색에 쓰는가. 위키가 보기에 앞의 둘은 잘 관리된 비즈니스 용어집([[데이터 거버넌스와 카탈로그]])으로도 채워지고, 세 번째가 온톨로지를 가른다. [[시맨틱 계층]]의 스펙트럼(용어 사전 → 공통 엔티티 모델 → 온톨로지·지식 그래프)에서 한 칸 위로 올라가는 조건이 그것이다.
