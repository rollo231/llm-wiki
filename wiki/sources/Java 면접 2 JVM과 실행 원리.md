## 요약

각 질문에는 등급별 모범 답과, 그 등급에 머문 "이유"가 붙어 있다. 등급 체계는 [[인프런 Java 면접 강의]]에 정리했다.

| 질문 | 쪽 | Gold 답의 요지 | Gold와의 차이("이유") |
|---|---|---|---|
| **Q1.** JVM의 장단점 | p2–4 | 장점 둘: OS와 Java 사이 중재자라 플랫폼 독립, GC가 메모리를 자동 관리해 휴먼 에러 예방. 단점: 바이트코드→기계어 변환 때문에 C/C++보다 느림. 다만 JIT가 격차를 줄였다 | Bronze는 장단점만 나열하고 원인·근거가 없다 |
| **Q1-1.** 자바는 왜 C/C++보다 느린가 | p5–7 | C/C++은 컴파일 시점에 이미 기계어다. 자바는 런타임에 인터프리터로 한 줄씩 해석하는 오버헤드가 있다. JIT가 자주 쓰는 코드를 컴파일해 실행할수록 격차가 준다 | Bronze는 인터프리터만 말한다. Silver는 JIT에 의한 개선이 빠졌다 |
| **Q2.** Java 실행 과정 | p8–10 | 5단계: ① JVM이 OS에서 메모리 할당 ② javac가 .java→.class ③ 클래스 로더가 필요한 시점에 로딩 ④ 런타임 데이터 영역 배치, 실행 엔진이 수행 ⑤ 필요에 따라 GC | Bronze는 개념만 말한다. Silver는 클래스 로더·GC 단계가 빠졌다 |
| **Q2-1.** 실행 엔진, 인터프리터 vs JIT | p11–13 | 실행 엔진은 적재된 바이트코드를 기계어로 바꿔 실행한다. 인터프리터는 한 줄씩이라 느리고, JIT는 이를 보완해 자주 실행되는 영역을 런타임에 컴파일한다 | Silver는 "자주 실행되는 코드" 기반이라는 설명이 빠졌다 |
| **Q2-2.** JIT는 "자주 쓰는 코드"를 어떻게 판단하나 | p14–16 | 메서드 호출 횟수를 프로파일링한다. C1은 약 2,000회, C2는 약 15,000회를 넘으면 컴파일한다 | Silver는 C1/C2와 임계치가 빠졌다 |
| **Q2-3.** 코드 캐시가 꽉 차면 | p17–19 | 새 코드는 컴파일되지 않고 인터프리터로 돌아 느려진다. 이미 컴파일된 메서드는 계속 컴파일된 코드로 실행된다 | Bronze는 "에러·중단"으로 추측한다. Silver는 인터프리터 전환과 성능 저하를 말하지 않는다 |
| **Q2-4.** 배포 직후 초기 요청이 느린 이유 | p20–22 | 부팅 직후엔 코드 캐시가 비어 모든 코드가 인터프리터로 돈다. 이때 트래픽이 몰리면 응답이 크게 느려지고, 심하면 서버가 다운된다. 해결책은 트래픽 노출 전에 주요 경로를 미리 실행하는 JVM Warming up | Silver는 코드 캐시가 비어 있다는 점과 워밍업이 빠졌다 |

p22에는 워밍업 관련 외부 영상 링크가 하나 있다.

## 핵심

- **섹션 전체가 "왜 느린가 → JIT → JIT의 한계 → 워밍업"이라는 한 줄기다.** 꼬리 질문이 앞 답의 마지막 단어를 붙잡고
  파고드는 구조라서, 한 답에서 JIT를 꺼내면 다음 질문은 JIT 내부로 들어간다. *(위키의 관찰)* → [[JIT 컴파일]]
- **워밍업 문제는 배포 전략 문제다.** 새 인스턴스가 차가운 채로 트래픽을 받는 상황은 롤링 배포·오토스케일 때 매번 생긴다.
  → [[JIT 컴파일]]
- **실행 과정은 [[JVM]] 페이지에 JVMS 기준 순서로 다시 적었다.**

## 주의·결함

- ⚠️ **Q2의 5단계는 순서가 틀렸다.** javac 컴파일은 빌드 시점에 JVM 밖에서 끝나는 일이라 "JVM 메모리 할당" 뒤에 올 수 없다.
  GC를 마지막 "단계"로 둔 것도 오해를 부른다. → [[JVM]]
- ⚠️ **Q2-2 임계치 숫자(2,000·15,000)는 JDK 25 기본값과 맞지만, "호출 횟수만" 센다는 설명은 틀렸다.** 루프 back-edge도
  함께 세고, 임계치는 동적으로 조정된다. → [[JIT 컴파일]]
- ⚠️ **Q2-3은 큰 방향은 맞지만 빠진 것이 있다.** 코드 캐시 flushing(기본 켜짐)으로 공간을 회수하면 컴파일이 재개될 수 있고,
  JDK 9부터 코드 캐시가 세그먼트로 나뉜다. → [[JIT 컴파일]]
- ⚠️ **Q2-4에는 클래스 로딩·초기화 비용이라는 원인이 빠졌고, 워밍업 말고 다른 해법(CDS, AOT 캐시 등)도 없다.** → [[JIT 컴파일]]
- Q1-1 Silver 답은 Bronze보다 C/C++ 비교만 하나 더 있다. 두 등급의 경계가 얇다.
