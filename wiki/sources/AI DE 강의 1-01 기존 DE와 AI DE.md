## 요약

기존 DE와 AI DE를 **데이터를 누가 소비하는가**로 가른다.

| | 기존 DE | AI DE |
|---|---|---|
| 목적 | 경영진이 현황을 파악하고 의사결정하도록 돕는다 | 모델이 학습하고 빠르게 추론하도록 돕는다 |
| 데이터 | 엑셀·ERP 같은 정형 테이블 | 이미지·오디오·비디오·텍스트까지 |
| 흐름 | 수집 → 클렌징(ETL/ELT) → DW 적재 → BI 대시보드 | 학습 데이터 준비 · 서빙 · 비정형 처리 |
| 핵심 과제 | 오류 수정·중복 제거, 거버넌스로 신뢰성 유지 | 버전 관리, 응답 속도, 비용·GPU |
| 강의의 비유 | 인사이트 제공자 | 시스템 건축가 |

AI DE의 역할 세 가지(p8):

- **모델 학습** — 고품질 학습 데이터 준비와 버전 관리, 학습 파이프라인 자동화·실험 관리, GPU 할당과
  학습 스케줄링.
- **추론** — 서빙 환경 구축과 응답 속도(latency) 최적화, 비용 효율적 인프라·오토스케일링, 모델 성능
  모니터링·로깅.
- **비정형 데이터** — 다양한 포맷 처리, 딥러닝 모델이 이해하는 텐서로 변환, 대용량 저장·검색.

"왜 지금 변해야 하는가"(p9–12)는 두 가지다: 비정형 데이터의 비중("80% 비정형 데이터", 인스타그램·유튜브
로고)과 실시간 수요의 증가(유튜브·쿠팡 로고).

## 핵심

- 코스 전체의 틀은 **"적재에서 모델 지원으로"**다. 이후 강의는 위 표의 오른쪽 열을 하나씩 채운다 — 학습
  쪽은 [[데이터와 모델 버전 관리]], 추론 쪽은 [[지연 시간과 처리량]], 비정형은 [[비정형 데이터 파이프라인]].
- 정합성·거버넌스는 여기서 기존 DE의 과제로 소개되지만, Part 1 후반([[데이터 SLA]]·
  [[데이터 거버넌스와 카탈로그]])에서 **소비자가 모델인 경우의 과제**로 다시 나온다.

## 주의

- 13p 중 내용이 있는 슬라이드는 4장(p6·p7·p8·p13)이고, 나머지는 섹션 타이틀과 로고 이미지다.
- "80% 비정형 데이터"는 슬라이드 제목뿐이고 출처가 없다. 같은 수치가
  [[AI DE 강의 1-09 비정형 데이터 수집과 전처리]]에서도 출처 없이 반복된다.
