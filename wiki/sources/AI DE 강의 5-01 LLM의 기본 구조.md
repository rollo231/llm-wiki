# AI DE 강의 5-01 LLM의 기본 구조

[[AI 데이터 엔지니어링 강의]] Part 5의 첫 강의. LLM이 무엇이고 어떻게 다음 토큰을 만드는지를 통계 언어 모델(N-gram)에서 RNN·LSTM, Transformer, GPT·BERT로 이어지는 역사와 함께 설명하고, 토큰화 → 임베딩 → Transformer → 출력의 동작 과정으로 마무리한다. 덱 `02`(「LLM과 RAG」)의 앞 두 장(p2–3)도 같은 내용을 짧게 되풀이하므로 이 페이지에 묶었다.

## 요약

### LLM의 정의 (덱 `01` p2, 덱 `02` p2–3)

- LLM은 대규모 텍스트로 학습한 Transformer 기반 딥러닝 언어 모델이고, 문맥을 보고 다음 단어의 확률을 예측한다(p2). 핵심 원리로 문맥 기반 예측, 자기회귀(생성한 토큰을 다시 입력으로 씀), 모든 단어에 대한 확률 분포 계산을 든다.
- 덱 `02` p2는 입력(질문·지시·문맥)과 출력(답변·요약·코드·번역), 활용(챗봇·검색 보조·문서 요약·코드 생성)을, p3는 대규모 사전학습 → 토큰화 → 어텐션 → 확률 예측(softmax, top-k 샘플링) → 출력 생성의 다섯 단계를 보여 준다. 덱 `01` p16과 같은 흐름이다.

### 앞선 언어 모델 (p3–5)

- N-gram(p3)은 연속한 N개 단어 묶음으로 다음 단어 확률을 추정하는 통계 모델이다. 단순하고 빠르지만 문맥 길이가 고정되고 희소성 문제가 있다.
- RNN(p4)은 은닉 상태(hidden state)에 앞 단어의 정보를 담아 순서대로 처리한다. 한계는 장기 의존성, 기울기 소실·폭발, 병렬화 어려움이다. 슬라이드는 "2014년 LSTM의 등장"으로 장기 의존성을 일부 해결했다고 적는다.
- NLP 발전 연표(p5)는 BoW(2010) → TF-IDF(2012) → Word2Vec(2013) → RNN/LSTM(2014) → Transformer(2017) → BERT/GPT(2018+)를 통계 기반 → 신경망 기반 → Attention 기반 → 대규모 모델의 네 시기로 묶는다. 연도는 슬라이드 그림에만 있다.

### Transformer (p6, p13–15)

- Self-Attention은 각 단어가 문장의 다른 모든 단어와의 관련성을 계산하고, Multi-Head Attention은 이를 여러 개 병렬로 돌려 문법·의미·대용어 같은 관계를 동시에 잡는다(p6, p13). 특징으로 병렬 처리, 긴 문맥, Positional Encoding을 든다.
- p13은 Query·Key·Value와 `softmax(Q·Kᵀ/√d_k)·V`를 "Attention Score"로 소개하고, 점수 계산을 내적 → √d_k 스케일링 → softmax → V 가중의 네 단계로 푼다.
- p14는 FFN(`max(0, xW₁ + b₁)W₂ + b₂`, 두 선형 변환과 ReLU)과 Residual 연결 + LayerNorm을, p15는 사인·코사인 Positional Encoding을 설명한다.

### 학습 방식과 모델 계열 (p7–10)

- 사전학습은 레이블 없는 대규모 데이터로 언어의 일반 패턴을 배우는 자기지도 학습이고, 파인튜닝은 사전학습 모델을 불러와 소량의 레이블 데이터로 학습률을 낮춰 미세 조정하는 과정이다(p7).
- GPT(p8)는 Transformer 디코더 기반 자기회귀 모델이다. p9는 GPT-1(1.17억) → GPT-2(15억) → GPT-3(1750억) → GPT-4(1.76조)의 파라미터 수를 연표로 보여 준다.
- p10은 GPT(디코더, 단방향, 다음 단어 예측, 생성)와 BERT(인코더, 양방향, 마스크드 언어 모델, 이해·분류·QA·NER)를 비교하고, 파라미터를 1750억(GPT-3)과 3.4억(BERT-base)으로 적는다.

### 토큰화와 임베딩 (p11–12)

- 토큰화는 텍스트를 모델이 처리할 단위로 나누는 전처리다(p11). BPE는 자주 등장하는 글자 쌍을 새 문자로 치환하는 방식으로, 자주 쓰는 어휘는 한 토큰, 드문 단어는 여러 토큰이 된다. 한국어는 조사·어미 변형이 많아 "자동차가" → "자동차" + "가"처럼 분리하는 것이 중요하다고 한다.
- Embedding Layer는 토큰 ID를 수백~수천 차원 벡터로 바꾸고, 뜻이 비슷한 단어가 가깝게 놓이도록 학습된다(p12). 왕·여왕·남자·여자의 3차원 예시를 든다.

### 전체 동작 과정 (p16)

입력 → 토큰화 → 임베딩(+ 포지셔널 인코딩) → Transformer → 출력의 다섯 단계. 출력 단계에서 언어 모델 헤드가 다음 토큰의 확률 분포를 계산하고, 한 토큰씩 생성해 입력 시퀀스에 붙이며, 더 생성할 필요가 없으면 멈춘다.

## 핵심

- 이 덱은 데이터 엔지니어가 RAG를 이해하기 위한 배경지식으로 LLM의 내부 구조를 한 번 훑는다. 데이터 쪽 이야기는 없고, 뒤의 [[AI DE 강의 5-02 임베딩과 벡터 검색]]·[[AI DE 강의 5-03 LLM의 한계와 RAG]]로 넘어가는 다리 역할이다. 이 평가는 위키의 것이다.
- 모델 계열, 역사, 사전학습과 파인튜닝, 컨텍스트 창은 [[대규모 언어 모델]]에 모았다.
- Self-Attention, Q·K·V, FFN, Residual, Positional Encoding(p6, p13–15)은 [[트랜스포머]]에 모았다.
- BPE와 한국어 토큰화(p11)는 [[토큰화]]에, 토큰 ID를 벡터로 바꾸는 층(p12)은 [[임베딩]]에 있다.

## 주의·결함

사실 관계는 2026-09-28에 원 논문과 공식 자료로 대조했다. 정정 문구와 근거 URL은 개념 페이지에 있다.

- ❌ LSTM은 2014년이 아니라 1997년 논문(Hochreiter & Schmidhuber)이다(p4). 근거는 [[대규모 언어 모델]]에 있다.
- ❌ 연표의 BoW(2010)·TF-IDF(2012)는 기원 연도로 보면 틀리다. IDF 가중치는 Spärck Jones 1972다(p5). 근거는 [[대규모 언어 모델]]에 있다.
- ❌ BERT-base는 1.1억(110M) 파라미터다. 3.4억(340M)은 BERT-large다(p10). 근거는 [[대규모 언어 모델]]에 있다.
- ❌ BPE를 "텍스트를 점점 더 적은 단위로 쪼개 나가는 방식"이라고 한 설명은 방향이 거꾸로다. BPE는 글자에서 시작해 자주 나오는 쌍을 병합해 나간다(p11). 근거는 [[토큰화]]에 있다.
- ⚠️ GPT-4의 "1.76조 파라미터"는 공식 수치가 아니다. OpenAI 기술 보고서는 모델 크기를 밝히지 않았다(p9). 근거는 [[대규모 언어 모델]]에 있다.
- ⚠️ p13이 "Attention Score"라고 부른 `softmax(QKᵀ/√d_k)·V`는 논문에서 어텐션의 출력이다. 가중치(점수)는 V를 곱하기 전의 softmax 값이다. 근거는 [[트랜스포머]]에 있다.
- ⚠️ ReLU FFN과 사인·코사인 Positional Encoding(p14–15)은 2017년 원 논문의 선택이다. LLaMA 같은 최근 모델은 SwiGLU와 RoPE를 쓴다. 슬라이드는 이 차이를 말하지 않는다. 근거는 [[트랜스포머]]에 있다.
- 예시 토큰화가 앞뒤로 다르다. p11은 "안녕하세요", "."를 따로 떼고, p16은 "안녕하세요."를 한 토큰으로 적는다. 둘 다 설명용 그림이라 실제 토크나이저 출력은 아니다. 위키의 관찰이다.
- 덱 `01` 안에서 Transformer가 세 번(p6, p13, p14) 따로 나오며, p6과 p14의 "Transformer 블록 구조" 그림은 층 이름만 조금 다른 비슷한 그림이다. 덱 `02` p2–3도 덱 `01`의 요약을 되풀이한다.
